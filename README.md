# PapersSpace
this is a note-taking site.

controls:
LMB - drag item around
RMB - edit hovered item
A/D - rotate held item
Q - snap to 45d angle
E - use held item / open hovered machine's UI
T - spawn a new stamp
L - switch language
Shift + MMB - point
